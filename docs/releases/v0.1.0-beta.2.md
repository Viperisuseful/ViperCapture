# ViperCapture OSS 0.1.0-beta.2 Developer Beta

This beta adds reliable native Windows validation, hardened Chromium runtime
fingerprints, operational readiness probes, same-host competitor benchmarking,
versioned release packages, and a production-oriented public API deployment
reference.

## Release evidence

- full Python unit and renderer suite;
- Chromium, Firefox, and WebKit smoke captures;
- React web and desktop lint/build checks;
- sustained concurrency and forced restart recovery artifacts;
- Docker rendering under a 1 GiB memory limit;
- checksummed source, SDK, Action, skill, integration, and Go bundles;
- versioned GHCR image built from the release commit.

## Beta boundaries

The API may still change before v1. Public operators own TLS, network egress,
capacity, alert delivery, backups, upgrades, abuse response, and support. The
included deployment is a hardened starting point, not a managed-service SLA.
