# ViperCapture OSS 0.2.0-beta.1 Developer Beta

This beta makes animated capture work the way a full-page recording should.
GIF, WebM, and MP4 output now moves from the top of the page to the bottom over
the requested duration instead of recording a static viewport. GIF and WebM
can preserve transparent page and side padding, while formats without alpha
use an opaque background.

Video quality is higher across the board. WebM uses a higher bitrate, MP4 uses
H.264 CRF 17, and GIF palettes are generated at full resolution and 15 FPS.
When compatible hardware and drivers are available, ViperCapture can encode
video through NVIDIA NVENC, AMD AMF, Intel Quick Sync, Apple VideoToolbox,
Windows Media Foundation, or Linux VA-API. A failed hardware render retries
with the software encoder. GIF and transparent WebM continue to use software
encoding so they keep their animation and alpha channel.

The browser interface includes the corrected full-page and transparency
controls.

## Beta boundaries

The API may still change before v1. Public operators remain responsible for
TLS, network egress, capacity, alert delivery, backups, upgrades, abuse
response, and support. The included deployment is a hardened starting point,
not a managed-service SLA.
